# capivaraoverlay-release

Downloads do **Capivara Overlay**.

O codigo-fonte fica em um repositorio privado; este repositorio existe apenas
para distribuir o instalador e alimentar a atualizacao automatica do aplicativo.

## Baixar

[CapivaraOverlay_0.1.0_x64-setup.exe](./CapivaraOverlay_0.1.0_x64-setup.exe)

Instalacao por usuario, sem necessidade de privilegio de administrador.

## Atualizacao automatica

O aplicativo le o  deste repositorio e se atualiza sozinho quando
ha uma versao mais nova.
